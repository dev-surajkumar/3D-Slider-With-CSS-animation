# 🐉 3D Image Slider – Dragon Carousel

This is a visually stunning **3D image slider** built with **HTML** and **CSS** only – no JavaScript required!  
Images rotate around a central axis with smooth animation using pure CSS `transform`, `perspective`, and `keyframes`.

---

## 🔥 Features

- 🎞️ **3D Rotating Carousel** – Powered by `rotateY()` and `translateZ()` for immersive effect.
- 🖼️ **Supports Multiple Images** – Easily configurable by setting `--quantity` and `--position`.
- ⚙️ **Fully Responsive Design** – With media queries to adapt on smaller screens.
- 🎨 **Custom Styling** – Beautiful background, glowing credits text, and smooth animations.
- 💡 **Pure CSS Animation** – No JavaScript, no dependencies.
